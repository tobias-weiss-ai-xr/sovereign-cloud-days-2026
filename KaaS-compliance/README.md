# KaaS Compliance — SCS-verified bare-metal K3s cluster

Source documents and dashboard for the SCS KaaS compliance of the openEduSuite cluster.

## Structure

- `network/` — network configuration, FIP assignment, firewall
- `security/` — DevSecOps hardening assessment, incident response plan
- `operations/` — SCS-compliant update routine (part 1 + 2/rollback)
- `monitoring/` — SCS compliance dashboard (Grafana)
- `references/` — compliance status, full implementation, KaaS test report
